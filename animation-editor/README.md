# 十二秒动画编辑器 — 月亮 · 纸船 · 小人

一个零依赖的 Canvas 关键帧动画编辑器：月亮先升起，纸船随后横穿舞台，
最后小人在岸边挥手。支持位置、旋转、缩放、透明度关键帧，Web Audio
同步合成风声、桨声和提示钟。

## 运行

```bash
cd animation-editor
python3 -m http.server 8080   # 或任意静态服务器
# 打开 http://localhost:8080
```

（ES module 需要经由 HTTP 加载，双击 index.html 无法运行。）

## 操作

- **播放头**：在时间轴刻度尺或轨道上按下并拖动，画布实时显示插值结果。
- **关键帧**：点「在播放头添加关键帧」新增；点击 ◆ 选中（点其他 ◆ 即重选）；
  「删除选中关键帧」按钮或 Delete 键删除。属性框中直接改数值时，
  有选中则改写选中关键帧，无选中则在播放头处自动新建。
- **走带**：播放/暂停（空格键）、停止、循环开关、声音开关。
- **工程**：保存会下载 `animation-project.json` 并缓存到 localStorage；
  载入可恢复该 JSON；刷新页面自动恢复上次保存的工程。
- **声音**：风声贯穿全程，纸船过河（3s–9s）响起桨声，小人出现（8.6s）
  敲响提示钟。播放、暂停、拖动、循环回卷时声音始终跟随播放头。

## 文件

| 文件 | 说明 |
| --- | --- |
| `core.js` | 关键帧轨道、线性插值、工程序列化、播放时钟（纯逻辑，无 DOM） |
| `shapes.js` | 月亮 / 纸船 / 小人的 Canvas 路径图形与舞台背景 |
| `audio.js` | Web Audio 合成：风声、桨声、提示钟，跟随播放头启停 |
| `editor.js` | UI  wiring：时间轴、属性面板、走带、保存/载入 |
| `test/core.test.mjs` | 核心逻辑测试（`npm test`，即 `node --test`） |
| `scripts/browser-smoke.mjs` | Playwright 浏览器冒烟测试（需 `npm i playwright`） |

## 验证

- `npm test`：14 个核心测试 —— 插值、关键帧增/删/重选、时钟的
  循环/暂停/寻址、工程 JSON 往返、示例工程时序、音频事件窗口。
- `node scripts/browser-smoke.mjs`：17 项浏览器检查 —— 页面加载、
  画布渲染、拖动插值、播放/暂停/循环/停止、音频跟随、关键帧
  增删改、保存后刷新恢复。
