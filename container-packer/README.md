# 集装箱三维装箱工具

面向仓库主管的装箱规划工具：在三维视角下把不同尺寸的设备箱装入 20 英尺标准集装箱
（内尺寸 590×235×240cm），支持箱子旋转、顺序调整与两种自动排布策略。

## 运行

纯静态页面，无需构建：

```bash
cd container-packer
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 功能

- **两种排布策略**：贪心装箱（按列表顺序首次适配 + guillotine 空间切分）、按体积降序。
- **箱子管理**：内置 12 个设备箱（尺寸 / 重量 / 不可倒置标记）；可逐箱指定朝向
  （含倒置）、上下调整顺序、增删箱子。
- **指标**：容积利用率、按重量加权的重心位置（画布中以红色十字标出）、不可倒置违规计数。
- **碰撞检测**：装箱后做两两 AABB 相交与边界检查；未通过或有箱子装不下时
  状态为「装箱未完成」，导出按钮禁用，不会宣称完成。
- **导出**：生成按层（底面高度 z）排列的装箱清单 `装箱清单.txt`。
- **三维视图**：Canvas 等距投影，拖动或按钮旋转视角，可剖开朝向观察者的侧壁。

## 测试

```bash
node test/packing.test.mjs   # 算法单元测试（无浏览器依赖）
node test/e2e.mjs            # 端到端测试（需要 playwright 与 Chromium）
```

`test/e2e.mjs` 需要能 `import "playwright"`（例如在仓库根目录 `pnpm install` 之后，
或在本目录安装 playwright），并用 `npx playwright install chromium` 装好浏览器。
端到端测试覆盖：内置 12 箱两种策略装箱完成且无穿模、视角旋转与剖开侧壁截图
（`test/shots/`）、分层清单、以及超高箱子（300cm > 内高 240cm）的失败提示。
